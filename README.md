# Atividades de JavaScript

Exercícios de lógica de programação em JavaScript puro, feitos durante a graduação em Análise e Desenvolvimento de Sistemas.

> **Trabalho antigo, feito por mim sem uso de IA.** A versão original (arquivo `.rar`) está preservada em [`Atividade-Desv.Web-original`](https://github.com/ColdAlchemy/Atividade-Desv.Web-original) para mostrar minha evolução.

## Exercícios
| Pasta | O que faz |
|---|---|
| `calculadora` | Calculadora com as operações +, -, * e / |
| `contagem-reg` | Contagem regressiva a partir de um inteiro positivo, com validação da entrada |
| `mediana-de-notas` | Lê quatro notas e calcula a mediana, validando os valores |
| `par-impar` | Informa se um número é par ou ímpar |

## Como rodar
Abra o `index.html` de cada pasta no navegador. Os scripts usam `prompt()` para ler a entrada e exibem o resultado com `alert()` ou no console do navegador.
